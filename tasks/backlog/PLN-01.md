# PLN-01: Candidate Ambient Screensaver Shaders (Authentic C-Matrix, Pixel Rain, Random Lasers, Rotating Tetriminos)

## 1. Candidate Concepts
1. **Authentic C-Matrix (Terminal Style)**:
   - True to the classic Unix/Linux `cmatrix` terminal utility.
   - Distinct character streams with varying speeds and lengths.
   - Crisp, high-contrast, pure green (or theme accent) phosphors.
   - Blinding white/bright lead character that shifts down line-by-line.
   - Trailing characters that dim down in discrete discrete terminal brightness steps rather than a blurry continuous canvas wash.
   - Character mutations (random glyph changes in place as drops fall) with bold/normal character attributes.
2. **Normal Pixel Rain**: Simple, elegant, minimalist retro vertical square/rect pixel bits without Japanese/Latin glyph overhead.
3. **Random Lasers**: High-energy geometric horizontal/vertical scanning beams cutting across viewport dead space to actively exercise LCD subpixels.
4. **Rotating Tetriminos**: Classic polyomino shapes gently floating, rotating, and drifting through space in soft accent colors.

## 2. Status
Roadmap candidate for user prioritization.
